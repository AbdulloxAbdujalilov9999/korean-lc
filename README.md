# Korean Talk

A self-paced Korean course for Uzbek speakers — cloned from the architecture of `truck-talk-webapp` (Truck Talk /
SpeakUp), adapted for Korean. **Everything in this app — interface, instructions, and the AI teacher — is in
Uzbek. The only two spoken languages anywhere in the app are Korean (what's being taught) and Uzbek. Never English.**

## Structure

One site, two independent courses, picked from the hub (`index.html`):

| | Section | Path | What it is |
|---|---|---|---|
| 1 | **O'quvchi kitobi** (Student's Book) | `/studentsbook/` | Full course: new vocabulary, dialogues, grammar, quizzes, role-play |
| 2 | **Mashq daftari** (Workbook) | `/workbook/` | Same topic order, complementary drilling vocabulary (colors, telling time, prices, formal/informal speech) |

Each course runs **1A then 1B**, in that fixed order — **1B is locked until every unit of 1A (including its review
day) is completed.** This isn't special-cased: units unlock strictly in `CURRICULUM` array order (finish unit *N* to
open unit *N+1*), and because every 1A entry precedes every 1B entry in that array, the level gate falls out of the
same rule for free. See `isUnlocked()` in `shared/course-engine.js`.

The last entry of each course is a **final test** (`"final":true`) whose question bank is built from *every single
lesson* in that course — not just the last few (`buildFinalTestQuestions()` in `shared/course-engine.js`). Passing
it (≥70%) marks the course finished and unlocks a printable certificate.

**Sunday is a built-in rest day**: finishing nothing on a Sunday never breaks your streak — the streak check skips
back over Sunday when deciding if "yesterday" counts (`prevStreakDate()` in `shared/course-engine.js`).

## Shared infrastructure

- `shared/course-engine.js` — the whole app (dashboard, lessons, flashcards, dialogue, role-play with mic scoring,
  practice, quiz, grammar book, homework/glossary, progress, settings, certificate). One file, parameterized per
  course by `window.KT_CONFIG = { ns, title, brand }` set inline in that course's `index.html` before this script
  loads (`ns` is the localStorage key prefix, so the two courses' progress never collide).
- `shared/grammar.js` — **one grammar book shared by both courses** (same as SNU Korean+'s own separate grammar
  booklet), explained entirely in Uzbek.
- `shared/teach-script.js` / `shared/teach-ui.js` — the narrated lesson slideshow (AI teacher layer 1): Korean words
  spoken aloud, Uzbek narration for everything else.
- `shared/tutor-ui.js` — the floating helper: lesson chat ("Bu dars"), translator, free-practice chat, plus a
  full-screen spoken conversation (text+mic fallback, or a live ElevenLabs voice call once configured) — AI teacher
  layers 2 and 3.
- `shared/neural-voice.js` — plays `/api/tts` audio (Korean or Uzbek only), falls back to the device's built-in
  voice, then to a silent reading pause, so a student is never met with silence.
- `shared/{tokens,theme,course}.css` — copied verbatim from truck-talk-webapp's design system (language-agnostic).

## Backend (`api/`, Vercel serverless functions)

Every one of these is **optional** — the app is fully usable with zero configuration, all progress stored in
`localStorage`. Each feature turns itself on the moment its env var(s) are set, with no code changes:

- `api/tts.js` — Korean + Uzbek text-to-speech via ElevenLabs. Only ever speaks phrases that exist in the course
  content (`api/_phrases.json` / `_phrases_uz.json`, generated by `npm run build-voices` — **run this after editing
  any `curriculum.js`**), so it can't be used as a free TTS proxy.
- `api/tutor.js` — the Claude-powered chat/translator/lesson-teacher. Needs `ANTHROPIC_API_KEY`.
- `api/agent.js` — signs a short-lived link to the ElevenLabs Conversational AI voice teacher. Needs
  `ELEVENLABS_API_KEY` + `ELEVENLABS_AGENT_ID` (create the agent from `elevenlabs/teacher.agent.json`).
- `api/_auth.js` — **currently a stub**: there's no Firebase project for this app yet, so every caller is let
  through as one shared identity (fine for a pilot / single-user use; the rate limiter is global instead of
  per-person until this is upgraded). The file documents exactly how to swap in real Firebase auth later without
  touching `tutor.js` or `agent.js`.

See `.env.example` for the full list of variables.

## Running it locally

No build step. Any static file server works:

```bash
npm run dev
```

Then open `http://localhost:8743/`. The AI-teacher backend calls will 404 (expected — there's no serverless runtime
locally); everything else works fully offline against `localStorage`.

## Adding more content

Each `curriculum.js` is an array of unit objects:

```js
{"d":1,"lvl":"1A","t":"<Korean title>","tu":"<Uzbek title>","gu":"<optional shared/grammar.js unit id>",
 "v":[["<Korean word/phrase>","<Uzbek meaning>","<Korean example sentence>"], ...],
 "dl":[["<speaker>","<Korean line>","<Uzbek line>"], ...],
 "g":["<short grammar title, Uzbek>","<short grammar explanation, Uzbek>"],
 "qz":[["<Uzbek question>",["optA","optB","optC","optD"],<correctIndex>], ...],
 "sp":["<Korean speaking prompt>","<Uzbek speaking prompt>"]}
```

A review unit (`"rev":true`) carries only `qz`/`sp`, no `v`/`dl`/`g`. The final test unit (`"final":true`) carries
only `d`/`lvl`/`t`/`tu` — its questions are generated automatically. Both courses currently ship a pilot: 3 teaching
units + 1 review per level (8 units) + the final test, per course. Add more units following the same shape — the
engine, AI teacher, and final-test question bank all pick up new content automatically; just re-run
`npm run build-voices` afterward so new Korean lines are allowed through `/api/tts`.

## Still open

- No Firebase project yet (needed for cross-device progress sync and account-gated AI-teacher access) — see
  `api/_auth.js`'s comment for the upgrade path.
- `ELEVENLABS_API_KEY` / Korean voice choice / `ANTHROPIC_API_KEY` / `ELEVENLABS_AGENT_ID` are all unset — the app
  runs fine without them (graceful fallback everywhere), but the AI teacher stays silent/disabled until provided.
- Branding icons in `icons/` are still the placeholder TruckTalk ones, copied over during scaffolding.
- Content is a pilot (8 units + final test per course) — extend following the schema above.
